# Домашнее задание к занятию «Подъём инфраструктуры в облаке (Terraform + Yandex Cloud)» Расулов Р. М.

## Архитектура и состав проекта
С помощью Terraform в облаке **Yandex Cloud** описана и развернута отказоустойчивая инфраструктура:
* **Сеть и маршрутизация (`network.tf`):** облачная VPC-сеть `develop-fops-20-05`, две подсети в зонах доступности `ru-central1-a` (`10.0.1.0/24`) и `ru-central1-d` (`10.0.2.0/24`), общий NAT-шлюз (`shared_egress_gateway`) для выхода приватных серверов в интернет, таблица маршрутизации и группы безопасности (`LAN`, `bastion_sg`, `web_sg`).
* **Вычислительные ресурсы (`main.tf`):** 4 прерываемые ВМ на базе образа `ubuntu-2204-lts`:
  * `bastion` — бастион-хост с публичным IP-адресом для безопасного SSH-доступа;
  * `web-a` и `web-b` — веб-серверы в приватных подсетях разных зон доступности;
  * `db` — сервер баз данных в приватной подсети.
* **Автоматизация настройки (`cloud-init.yml` и Ansible):** автоматическая генерация inventory-файла `hosts.ini` через ресурс `local_file` с настройкой `ProxyCommand` для доступа к приватным ВМ через бастион-хост.

### Задание 2. Установка и запуск веб-сервера Nginx
* Написан плейбук `nginx.yml`, устанавливающий и запускающий службу `nginx` на группе хостов `[webservers]`.
* Проверена корректность работы веб-серверов (`HTTP/1.1 200 OK` на локальном порту 80 обеих машин).

### Задание 3*. Масштабирование инфраструктуры и развёртывание СУБД
* В `main.tf` добавлена виртуальная машина `db` и обновлена генерация `hosts.ini` (добавлена группа `[databases]`).
* Написан плейбук `db.yml`, устанавливающий и запускающий службу **PostgreSQL**.
* Через Ansible (`systemctl is-active`) подтверждена активность служб `nginx` на веб-серверах и `postgresql` на сервере БД.

### Задание 4*. Безопасная аутентификация через переменные окружения
* Настроен профиль утилиты `yc` CLI (`yc init`).
* Из `providers.tf` удалены упоминания файлов ключей и чувствительных идентификаторов.
* Настроен автоматический экспорт переменных окружения `YC_TOKEN`, `YC_CLOUD_ID` и `YC_FOLDER_ID` через `~/.bashrc`.
* После завершения проверок все облачные ресурсы удалены командой `terraform destroy`.
